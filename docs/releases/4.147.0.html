Version 4.147.0

Variable fonts and modern paths · NuGet (prerelease)

Superseded by 4.148.0 · Never released as stable — these changes rolled up into 4.148.0.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

The v4 previews bring Skia m147, variable fonts, and animated WebP encoding to SkiaSharp. New APIs expose color-font palettes, surface sampling, CICP color spaces, and stream-backed data. The engine transition also changes default fonts, path construction, Vulkan requirements, and supported native platforms; review the migration notes before upgrading.

Breaking Changes

  • Build paths with SKPathBuilder — Skia paths are immutable upstream. SKPath mutation methods remain compatibility shims but are obsolete; construct geometry with SKPathBuilder and use Detach or Snapshot to obtain an SKPath. Prefer the builder overloads of SKPaint.GetFillPath and SKPathMeasure.GetSegment. (#3702)
  • Choose an explicit font and revise missing-font checks — new SKFont() and a null Typeface now use SKTypeface.Empty, so they measure zero and draw no glyphs. Pass SKTypeface.Default or another explicit typeface and use IsEmpty rather than a null check. Legacy SKPaint starts and resets with Default. On Android, FromFamilyName returns Default for a missing family; use SKFontManager.Default.MatchFamily when a null result is required to detect no match. (#3730)
  • Keep stream move offsets within the 32-bit range — SKStream.Move(long) is obsolete and now throws OverflowException for offsets outside the int range instead of silently truncating them. Validate offsets and call Move(int). Negative native moves on LP64 targets are corrected. (#3714)
  • Require Vulkan 1.1 before context creation — Ganesh Vulkan now requires Vulkan 1.1 and can terminate the process on Vulkan 1.0 instead of returning null. Create the VkInstance with apiVersion at least 1.1 and explicitly set GRVkBackendContext.MaxAPIVersion to the matching supported version; do not leave it at zero. On 1.0-only devices choose raster or another backend before calling CreateVulkan. (#3702)
  • Update Vulkan conversion types and native interop layouts — GRVkImageInfo.YcbcrConversionInfo now uses GRVkYcbcrConversionInfo. Migrate from the Gr-prefixed compatibility type and its removed value-equality operators, and account for Components when constructing layouts. Custom GRVkBackendContextNative users must remove legacy version/ownership fields, use fVkExtensions and fDeviceFeatures/fDeviceFeatures2, and manage instance/device ownership themselves. (#3560, #3702, #4001)
  • Move Tizen and WebAssembly consumers to supported baselines — Tizen arm/x86 native assets are removed; use tizen-x64 or tizen-arm64. WASM native linking now requires .NET 8 or later for both SkiaSharp and HarfBuzzSharp, with explicit build errors on .NET 6/7. Managed Blazor assemblies still include net6.0; that does not restore native WASM support on those runtimes. (#3702, #4022)
  • Adjust APIs changed during the previews — HarfBuzz palette APIs return HBColor instead of raw uint values; use its channel properties or SkiaSharp.HarfBuzz color conversions rather than casting to SKColor. SKDocumentXpsOptions.DPI is renamed Dpi. These replace APIs introduced during the v4 previews, not stable v3 members. (#4000, #4001)

Engine

  • Skia m147 and expanded color formats — Advances from m119 through m132 and m133 to m147, bringing upstream codec and color-pipeline improvements. Adds HDR color formats, R16Unorm, and SKColorSpace.CreateCicp for H.273 color-space definitions. — ❤️ @ramezgerges (#3560, #3660, #3702)

API Surface

  • Variable fonts and color palettes — Query variation axes and design positions, clone typefaces at chosen coordinates, and select or override color-font palettes. Span overloads support allocation-conscious access, and undersized variation buffers return the values that fit. — ❤️ @ramezgerges (#3703, #3742)
  • Animated encoding and memory-backed streams — SKWebpEncoder encodes animated WebP from pixmaps and frame durations. SKStream.GetData returns ref-counted data without copying when cheaply available, or null otherwise; returned data survives stream disposal. (#3771, #3772)
  • Explicit sampling and resource operations — Adds SKSamplingOptions overloads for surface drawing, XPS options on document creation, per-image and per-surface GPU flush, and shader-backed mask filters. (#3491, #4001)

Bug Fixes

  • Font, path, and view reliability — Fixes SKPath finalizer ordering, recursive ContainsGlyphs calls, Android default-font startup, and MAUI Android rendering after tab reattachment. Nano Server uses an empty font manager rather than calling unavailable DirectWrite services. — ❤️ @ramezgerges, @SimonvBez (#3796, #3742, #3730, #3076, #3835)
  • Apple workload compatibility — Apple library TFMs use the base 26.0 platform version rather than requiring 26.2, allowing consumers to use compatible base 26.x workloads. (#3798)

Platform

  • Linux Bionic native assets — Adds linux-bionic x64 and arm64 variants for SkiaSharp and HarfBuzzSharp, without fontconfig dependencies. — ❤️ @4Darmygeometry (#3217)

Security

  • Refreshed image and font dependencies — Updates libpng to 1.6.58, libexpat to 2.7.5, FreeType to 2.14.3, zlib to 1.3.2.1, and libjpeg-turbo to 3.1.4.1. (#3718, #3717, #3726, #3720, #4012)

HarfBuzzSharp 8.3.1.6

Adds variable-font axis and named-instance APIs, color-palette queries, and HBColor with SkiaSharp color conversions. Linux Bionic assets are available, while Tizen is 64-bit only and native WASM linking requires .NET 8 or later; the 8.3.1.6 package revision does not upgrade the HarfBuzz engine.
