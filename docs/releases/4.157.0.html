Version 4.157.0

Highlights

SkiaSharp 4.157.0 brings Skia m157 with image-filter, glyph and GPU rendering fixes. The release improves filtered-image boundaries, transformed geometry and text rendering, and makes LibraryImport calling conventions explicit. Graphite Metal's native iOS and tvOS minimum rises to 15; higher managed or framework requirements still apply.

Breaking Changes

  • Check Graphite Metal deployment requirements — Graphite Metal now requires iOS or tvOS 15 at the native engine level; its macOS minimum remains 12. Raise deployment requirements for applications using this backend where necessary, and continue to satisfy any higher managed or framework minimums. This is not a new minimum for every SkiaSharp backend. (#5542)

Engine

  • Updated to Skia m157 — Moves the bundled renderer to milestone 157. HarfBuzzSharp's package revision moves to 14.4.0.200 for this milestone; the bundled native HarfBuzz engine remains 14.4.0. (#5542)

Bug Fixes

  • More reliable filtered-image sampling — Keeps antialiased and MSAA image draws within their intended subsets under minification or skew, and aligns image-filter cache equality with hashing. Displacement offsets now use fp32 arithmetic to match filter bounds rather than rounding at fp16 precision. (#5770, #5710)
  • Corrected path and transformed geometry rendering — Fixes convex antialiased path bounds and a heap overflow across vertical clip gaps, clamps software coverage masks, and corrects reflected zero-length hairline square caps. Transformed ellipses and rounded rectangles use corrected radii and stroke-width mapping, with corner radii constrained to the transformed bounds. (#5612, #5630, #5670, #5688)
  • More robust glyph rendering and replay — Handles regenerated glyph outlines and incompatible mask formats, and preserves clipped embossed-mask planes. Direct-mask Slug replay gains validation for unsupported data, while Ganesh rounds text-atlas indices to avoid selecting the wrong texture. (#5748, #5612, #5630, #5670)
  • GPU clipping and submission corrections — Fixes Graphite clip keys, wedge inflation and readback stride, and Ganesh atlas state after empty flushes. Oversized Graphite clip-stack draws are skipped with a warning instead of exceeding pass capacity. Vulkan fixes cover initialization, affected ARM driver cleanup and native synchronous wait failures; managed GRContext.Submit remains void. (#5612, #5630, #5670, #5688, #5710)
  • Explicit cdecl for LibraryImport bindings — Generated LibraryImport declarations now select cdecl explicitly, matching the existing DllImport and delegate paths. This corrects an ABI mismatch risk on Windows x86 without changing public APIs or native exports. (#5565)

HarfBuzzSharp 14.4.0.200

HarfBuzzSharp's generated LibraryImport declarations now explicitly use cdecl, matching its DllImport and delegate paths. This corrects an ABI mismatch risk on Windows x86 without changing the public API.
