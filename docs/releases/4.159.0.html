Version 4.159.0

GPU meshes and Skia m159 · NuGet (prerelease)

Highlights

SkiaSharp 4.159.0 brings custom GPU mesh drawing alongside the Skia m159 engine update. The release candidate adds programmable vertex meshes, corrects iOS and tvOS device frameworks, and incorporates upstream glyph, image-filter cache, and Vulkan fixes. WebAssembly consumers must use .NET 9 or later; non-WebAssembly .NET 8 support is unchanged.

Breaking Changes

  • Use .NET 9 or later for WebAssembly — SkiaSharp and HarfBuzzSharp no longer ship .NET 8 WebAssembly native assets, and their build targets reject unsupported WebAssembly frameworks. Upgrade WebAssembly projects to .NET 9 or later and use the runtime-matched native archives; newer archives cannot substitute for an older .NET toolchain. Non-WebAssembly .NET 8 support is unchanged. (#5700)

Engine

  • Skia milestone 159 — Updates the bundled renderer with WebAssembly SIMD CPU rasterization, Windows font-loading improvements, and image/rendering correctness fixes. (#5685)

API Surface

  • Programmable GPU meshes — SKMeshSpecification, indexed and non-indexed mesh builders, vertex/index buffers, and SKCanvas.DrawMesh expose custom SkSL vertex and fragment programs with uniforms and child effects. Meshes draw only on GPU-backed surfaces; raster drawing is a no-op. Built meshes retain native resources after their source wrappers are disposed. (#5760)

Bug Fixes

  • Correct iOS and tvOS device frameworks — SkiaSharp and HarfBuzzSharp device frameworks now contain only arm64 device binaries and matching platform metadata, avoiding App Store validation failures caused by simulator slices. Simulator frameworks retain both x86_64 and arm64 support. — ❤️ @kdpkke (#5649)
  • More robust mask-filtered glyph rendering — Handles font scalers whose repeated glyph loads change paths, mask formats, or bounds. The native renderer uses the reloaded glyph state, clears incompatible masks, and correctly copies clipped emboss masks. (#5741)
  • Imagination Vulkan allocation failure handling — Ganesh and Graphite avoid a driver failure when descriptor-set allocation reports host or device out-of-memory on Imagination GPUs. The workaround is limited to that vendor and those allocation errors. (#5741)
  • Consistent image-filter cache keys — Makes image-filter cache equality agree with hashing for signed zero, matrix type-mask state, and subnormal translations, correcting native cache lookup behavior without changing package or ABI versions. (#5769)

HarfBuzzSharp 15.0.0.100

HarfBuzzSharp now requires .NET 9 or later for WebAssembly, while non-WebAssembly .NET 8 support is unchanged. Its iOS and tvOS device frameworks now use device-only binaries and matching metadata, retaining separate simulator support; package revision 15.0.0.100 keeps native HarfBuzz at 15.0.0 with no public managed API changes.
