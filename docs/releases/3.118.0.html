Version 3.118.0

Engine refresh and WebAssembly compatibility · NuGet (prerelease)

Superseded by 3.119.0 · Never released as stable — these changes rolled up into 3.119.0.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

The 3.118 previews advance to Skia m118 and improve .NET 9 WebAssembly compatibility. Android native assets gain 16 KB alignment, and Metal backend render-target APIs become available across platforms.

Breaking Changes

None in this preview line.

Engine

  • Skia m118 renderer — Updates the bundled engine through milestones 117 and 118, with matching managed and native bindings. (#3047, #3048)

Bug Fixes

  • WebAssembly imports and .NET 9 startup — Fixes .NET 9 Blazor issues, extends the WASM workaround to applications that do not reference Blazor views, and corrects imports when an application uses a base path. (#3064, #3082, #3088, #3092)
  • Native asset package paths — Corrects the PackagePath attribute used to place packaged assets. (#3101)

Platform

  • Android 16 KB alignment — Moves Android native builds to NDK r27c and 16 KB page alignment. (#3099)

API Surface

  • Cross-platform Metal render-target bindings — Makes the Metal API on GRBackendRenderTarget available across all platforms. — ❤️ @spouliot (#3070)

Security

  • Bundled dependency refresh — Updates libexpat to 2.6.4 and FreeType to the 2.13.3-based revision, and refreshes the libjpeg-turbo 2.1.5.1-based dependency. (#3056, #3061, #3060)

HarfBuzzSharp 8.3.1

HarfBuzzSharp receives Android 16 KB alignment and package-path corrections. WASM workaround changes also cover consumers outside the Blazor views package.
