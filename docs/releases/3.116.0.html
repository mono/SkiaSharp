Version 3.116.0

First stable v3 graphics release · Released December 2, 2024 · NuGet · GitHub Release

Supersedes 3.0.0 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.116.0 brings the v3 API and Skia m116 to a stable release. The release combines accelerated WinUI, WPF, and Mac Catalyst views with richer picture and shader APIs. WebAssembly gains threading and SIMD choices, while Span overloads reduce the need for temporary arrays.

Breaking Changes

  • Replace the removed 2.88 legacy surface — Previously obsolete APIs and types are removed. Use GRBackendTexture and GRBackendRenderTarget instead of legacy descriptors, SKSurfaceProperties instead of SKSurfaceProps, and SKFont-based text-blob overloads. Rebuild against v3 and follow the linked API diffs for other replacements. (#2539)
  • Move away from UWP and watchOS — The v3 packages no longer support UWP or watchOS. Migrate applications to supported platforms or retain a compatible older SkiaSharp release. (#2505)
  • Adjust matrix and encoder-option code — SKMatrix44 changes from a disposable object to a value type; remove disposal and reference-identity assumptions and use current matrix operations such as TryInvert(out ...). JPEG, PNG, and WebP encoder option properties are read-only, so construct configured options instead of setting properties afterward. Review changed ref-matrix call sites in the API diff.
  • Migrate filter crops and runtime shaders — SKImageFilter.CropRect and older filter signatures are removed. Use current SKRect-based overloads where applicable. Replace SKRuntimeEffect.Create with CreateShader for shaders and remove the isOpaque argument from ToShader calls; use the corresponding color-filter or blender factories for those effects.
  • Update custom view integration — Use OnPaintSurface instead of removed Android OnDraw/OnDrawFrame or Apple DrawInSurface overrides, and PaintSurface instead of SetRenderer. MAUI controller interfaces are removed. WinForms SKGLControl uses the newer OpenTK GLControl base without the old GraphicsMode constructors. Blazor's old Internal action-helper types are also removed; migrate any direct dependencies to supported APIs. (#2989)

Engine

  • Skia milestone 116 — The first stable v3 release uses the Skia m116 renderer introduced during the preview cycle. (#2829)

API Surface

  • Reusable pictures and programmable drawing — Adds SKBlender, raw image shaders, Skottie animation-builder bindings, and SKPicture playback and size APIs, together with R-tree picture recording. (#2830, #2748, #2630, #2883, #2889)
  • Span-based geometry and pixel access — MapPoints, MapVectors, and AddPoly accept spans to process multiple points without a temporary heap array. Color filters and SetRectRadii gain Span overloads, pixel spans accept coordinates, and Blazor components expose DPI. — ❤️ @alexandrvslv, @Youssef1313, @beto-rodriguez (#3030, #2879, #2949, #2609, #1832)

Platform

  • Accelerated desktop and Catalyst views — Adds WinUI SKSwapChainPanel with ANGLE native assets and WPF SKGLElement. Mac Catalyst uses Metal, and Metal bindings are available from a common .NET target. — ❤️ @gmurray81, @maxkatz6 (#2733, #2970, #2317, #2747, #2788)
  • WebAssembly execution variants — Adds multithreaded and SIMD WebAssembly options alongside non-SIMD assets, including Emscripten 3.1.56 binaries for .NET 9. — ❤️ @jeromelaban (#2620, #2612, #3010)

Bug Fixes

  • Rendering and disposal stability — Corrects Metal snapshot colors, MAUI view leaks, cloned-paint disposal, kerning-pair adjustments, and Uno canvas pixel format, resizing, and unload handling. PNG encoding returns to the 2.88.8 behavior. — ❤️ @taublast, @jeremy-visionaid, @pdjonov, @Youssef1313, @jeromelaban, @sungaila (#2804, #2955, #2904, #2858, #2918, #2922, #2854, #3014)
  • WebAssembly startup and base paths — Fixes .NET 9 Blazor issues, applies the WASM workaround outside Blazor views, and corrects imports for applications hosted beneath a base path. (#3081, #3087, #3089, #3093)

HarfBuzzSharp 8.3.0

HarfBuzzSharp gains multithreaded and SIMD WebAssembly assets and broader WASM workaround coverage. Native interop moves to function pointers and LibraryImport.
