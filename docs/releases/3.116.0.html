Version 3.116.0

First stable SkiaSharp v3 · Released December 2, 2024 · NuGet · GitHub Release

Supersedes 3.0.0 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.116.0 is the first stable v3 release, bringing modern .NET, Skia, and cross-platform view updates. It rolls up the v3 preview work with API additions, WebAssembly improvements, refreshed native components, and fixes across supported UI platforms.

Breaking Changes

  • Legacy obsolete APIs were removed — Members previously marked obsolete are no longer available in v3. Update code to the documented replacement APIs before upgrading.

Engine

  • Skia and HarfBuzzSharp updated — The stable v3 release includes refreshed graphics and text-shaping engines. (#3089, #3087)

API Surface

  • Expanded drawing and picture APIs — New span-based overloads and picture-recording capabilities make common managed drawing scenarios more efficient and expressive. (#3079, #2971)

Platform

  • Improved WebAssembly and desktop views — v3 improves WebAssembly support and adds or refines view integrations across desktop and mobile platforms. (#3088, #3064)

HarfBuzzSharp 8.3.0

HarfBuzzSharp 8.3.0 ships with the v3 release and updates the bundled text-shaping stack.
