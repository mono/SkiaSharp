Version 4.150.0

Skia m150 and filter APIs · Released July 7, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.150.0 brings Skia m150, new image-filter APIs, and faster CPU blur rendering. Paint bounds and overdraw visualization make drawing diagnostics easier. Existing pre-v4 deprecations now require migration, and the deprecated notebook integration is no longer included.

Breaking Changes

  • Remaining pre-v4 obsolete APIs become compile errors — Replace sampleCount-based Vulkan/Metal GRBackendRenderTarget constructors with their counterparts without sampleCount. Use run-buffer Glyphs and Positions properties instead of obsolete span accessors, SKFontHinting instead of SKPaintHinting, and SKSamplingOptions instead of SKFilterQuality. The obsolete enum types remain in implementation assemblies for ABI compatibility but are absent from reference assemblies. (#4195)
  • Notebook integration no longer ships — The SkiaSharp NuGet package no longer embeds its deprecated .NET Interactive/Polyglot Notebooks extension. Notebook consumers must provide their own rendering integration rather than rely on the removed extension. (#4186)

Engine

  • Skia updated to m150 — Updates the bundled renderer from m148 while preserving PDF support on Tizen and the existing Windows runtime floor. (#4146)
  • Bundled HarfBuzz updated to 14.2.1 — Includes AAT and Arabic fallback-shaping corrections, COLR v1 fixes, and glyph-extents improvements. (#4167)

API Surface

  • Composable image-filter nodes — CreateCrop restricts filter output with a rectangle and tile mode; CreateEmpty discards input to transparent black. (#4229, #4228)
  • Paint bounds and overdraw diagnostics — SKPaint.GetFastBounds returns conservative bounds when available for quick-reject culling. SKColorFilter.CreateOverdraw maps draw counts to a caller-supplied six-color palette. (#4271, #4227)

Bug Fixes

  • CPU blur performance restored — Small-sigma blurs of 8888 images use the faster dedicated approximation path instead of the regressed raster-pipeline path. — ❤️ @ramezgerges (#4269)
  • Apple typeface stream access synchronized — Corrects a native data race between opening and reusing a CoreText-backed typeface stream. (#4190)

Lifecycle & Internals

  • Surface canvas access avoids repeated interop — SKSurface.Canvas reuses its managed wrapper across calls and recreates the wrapper if it was explicitly disposed. — ❤️ @ramezgerges (#4247)

HarfBuzzSharp 14.2.1

The HarfBuzzSharp test suite moves to xUnit v3; this collected HarfBuzz-specific work does not introduce new shaping APIs.
