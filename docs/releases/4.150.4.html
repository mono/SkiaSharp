Highlights

SkiaSharp 4.150.4 corrects glyph-atlas reuse and shared stencil tracking. Windows HarfBuzz native assets also stop triggering the BinSkim BA2007 disabled-warnings error.

Breaking Changes

None in this release.

Bug Fixes

  • Glyph-atlas and stencil bookkeeping corrected — Partial glyph updates no longer mark earlier evicted glyphs current. Shared stencil-clear bounds are tracked in native coordinates across differing surface origins. (#5113, #5083)
  • Windows HarfBuzz binaries pass BinSkim BA2007 — Consumers no longer need to baseline the disabled-critical-warnings error in libHarfBuzzSharp.dll. The native exports and shaping behavior are unchanged; other existing BinSkim warnings are unaffected. (#5123)

HarfBuzzSharp 14.2.1.4

The Windows native library now passes BinSkim BA2007 by scoping vendored-source warning suppression. The bundled HarfBuzz engine and exported ABI are unchanged.
