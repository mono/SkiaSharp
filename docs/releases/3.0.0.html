Highlights

SkiaSharp 3.0 previews modern .NET support, updated Skia, and substantial API and platform improvements. This preview line introduced the foundations of SkiaSharp v3, including updated native dependencies, broader view support, and modernized drawing APIs.

Breaking Changes

  • Legacy obsolete APIs were removed — Members previously marked obsolete are no longer available. Update code to the recommended replacement APIs before moving to the v3 preview packages.

Engine

  • Skia and native dependencies updated — The v3 preview line refreshes the bundled graphics engine and native libraries for current rendering and text capabilities. — ❤️ @maxkatz6 (#3089, #2917)

API Surface

  • New span-based drawing APIs — New span overloads for point mapping, polygons, and rounded-rectangle radii reduce allocations in high-throughput drawing code. (#3079, #2971)

Platform

  • Modern .NET and view support — The preview adds .NET 9 support and broadens desktop, mobile, and WebAssembly view integration. (#3065, #3001)

HarfBuzzSharp 8.3.0

Updates HarfBuzzSharp alongside the SkiaSharp v3 preview line with current text-shaping support.
