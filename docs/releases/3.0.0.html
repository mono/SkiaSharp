Version 3.0.0

Previewing the v3 graphics API · NuGet (prerelease)

Superseded by 3.116.0 · Never released as stable — these changes rolled up into 3.116.0.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

The v3 previews introduce Skia m116 and expand accelerated drawing across desktop and mobile views. WinUI gains accelerated panels, Mac Catalyst uses Metal, and WPF gains SKGLElement. New picture, shader, and pixel-access APIs accompany a substantial migration from the 2.88 API surface.

Breaking Changes

  • Replace removed legacy APIs before upgrading — Previously obsolete APIs and types are removed. Replace legacy GPU descriptors with GRBackendTexture or GRBackendRenderTarget, use SKSurfaceProperties instead of SKSurfaceProps, and move text-blob construction to SKFont-based overloads. Rebuild consumers against v3 and use the linked API diffs for the remaining replacements. (#2539)
  • Migrate unsupported UWP and watchOS applications — UWP and watchOS support is removed. Keep those applications on a compatible older release or move them to a supported platform before adopting v3. (#2505)
  • Treat SKMatrix44 as a value — SKMatrix44 is now a value type, not a disposable SKObject. Remove disposal and reference-identity assumptions, replace removed mutating methods with the current matrix APIs, and use TryInvert(out ...) for inversion. Review ref-based matrix call sites against the API diff.
  • Update filter and runtime-effect construction — SKImageFilter.CropRect and older filter overloads are removed; migrate to current overloads using SKRect where applicable. Runtime shaders use SKRuntimeEffect.CreateShader instead of Create, and ToShader no longer accepts isOpaque. JPEG, PNG, and WebP option properties lose setters; construct configured options rather than assigning properties afterward.
  • Update view subclasses and WinForms OpenGL integration — Replace removed Android OnDraw/OnDrawFrame and Apple DrawInSurface overrides with OnPaintSurface, and use PaintSurface rather than SetRenderer. MAUI canvas controller interfaces are removed. SKGLControl moves to the newer OpenTK GLControl base and drops the GraphicsMode constructors; update custom initialization accordingly. (#2989)

Engine

  • Skia m116 baseline — The preview line moves the bundled renderer to Skia milestone 116. (#2829)

API Surface

  • More control over reusable drawing — Adds SKBlender, SKImage.ToRawShader, Skottie animation-builder bindings, and SKPicture playback and size APIs. Picture recording also gains an R-tree overload. (#2830, #2748, #2630, #2883, #2889)
  • Span and pixel-access overloads — Adds offset-based GetPixelSpan access, Span-based color-filter and rounded-rectangle helpers, SKFilterQuality compatibility overloads, and Blazor component DPI access. — ❤️ @Youssef1313, @beto-rodriguez (#2609, #2879, #2949, #2963, #1832)

Platform

  • Accelerated views on more UI stacks — WinUI gains ANGLE-backed SKSwapChainPanel and native assets, Mac Catalyst switches to Metal, and WPF adds SKGLElement. Metal APIs are also exposed from a common .NET target. — ❤️ @gmurray81, @maxkatz6 (#2733, #2970, #2747, #2317, #2788)
  • .NET 9 WebAssembly assets — Native builds add Emscripten 3.1.56 for .NET 9, while non-SIMD variants remain available for browser configurations that need them. — ❤️ @jeromelaban (#3010, #2612)

Bug Fixes

  • View rendering and resource cleanup — Fixes magenta Metal snapshots, MAUI view memory leaks, disposal of cloned paints, and Uno canvas color format and resize-background behavior. Unloaded Uno canvases also handle a missing XamlRoot safely. — ❤️ @taublast, @jeremy-visionaid, @Youssef1313, @jeromelaban (#2804, #2955, #2904, #2918, #2922, #2854)
  • Encoding and geometry compatibility — Restores the 2.88.8 PNG encoding behavior, honors paint filter quality in obsolete sampling overloads, fixes kerning-pair adjustments, and rounds rectangle conversions outward so partial edges are not truncated. — ❤️ @sungaila, @pdjonov (#3014, #2924, #2858, #2568)

HarfBuzzSharp 8.3.0

HarfBuzzSharp adopts function pointers and LibraryImport interop alongside the refreshed .NET target setup. Legacy obsolete binding APIs are removed as part of the v3 modernization.
