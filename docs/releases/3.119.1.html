Version 3.119.1

Apple rendering and lifecycle fixes · Released September 12, 2025 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.119.1 improves Apple view reliability and fixes unpackaged WinUI applications. This servicing release also adds typeface PostScript names, corrects UTC date conversion, and makes canvas restoration safer after disposal.

Breaking Changes

None in this release.

Bug Fixes

  • Apple view behavior — Avoids initializing SKMetalView twice, fixes Metal on iOS 15 and earlier, and preserves SKXamlCanvas transparency on Mac Catalyst. — ❤️ @jeremy-visionaid, @taublast, @spouliot (#3256, #3293, #3236)
  • Safe canvas restoration and UTC handling — SKAutoCanvasRestore avoids crashing when the canvas has already been disposed. Date conversion handles UTC inputs rather than assuming every DateTime is local. — ❤️ @taublast, @jeremy-visionaid (#3291, #3333)
  • Unpackaged WinUI applications — Corrects the EGL and GLESv2 build configuration for unpackaged WinUI apps and statically links the WinUI interop runtime. (#3338, #3341)

API Surface

  • Typeface PostScript names — Adds SKTypeface.PostScriptName for identifying a font's PostScript name. — ❤️ @jonlipsky (#3263)

Security

  • Updated zlib dependency — Refreshes bundled zlib to a 1.3.0.1-based revision. (#3058)

HarfBuzzSharp 8.3.1.2

No HarfBuzzSharp binding changes shipped in this release — it rebuilds the same HarfBuzz as the previous line.
