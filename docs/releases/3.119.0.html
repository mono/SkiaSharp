Version 3.119.0

Skia m119 and wider GPU support · Released April 25, 2025 · NuGet · GitHub Release

Supersedes 3.118.0 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.119.0 adds Direct3D on Windows and broadens Linux architecture support on the Skia m119 engine. Windows ARM gains OpenGL, tvOS gains SKMetalView, and Android libraries support 16 KB pages. New save-layer and color-filter APIs accompany fixes for WebAssembly, legacy .NET packaging, and image creation.

Breaking Changes

None in this release.

Engine

  • Skia m119 baseline — Advances through the m117 and m118 previews to Skia m119, with updated GPU context bindings and a new color type. (#3047, #3048, #3062)

Platform

  • More GPU backends and views — Adds Direct3D bindings and native support on Windows, enables OpenGL on Windows ARM, and adds tvOS SKMetalView. Metal render-target APIs are available across platforms, and iOS Simulator Metal performance is improved. — ❤️ @Kation, @MartinZikmund, @spouliot, @taublast (#2823, #3189, #3114, #3070, #3156)
  • Linux architectures and Android page sizes — Adds RISC-V 64-bit and LoongArch64 native build support, extends Alpine cross-compilation, and broadens Linux coverage using Debian 10. Android native libraries move to NDK r27c with 16 KB alignment. — ❤️ @kasperk81, @4Darmygeometry (#3192, #3198, #3200, #3209, #3096)

API Surface

  • Layer and color-filter control — Exposes SkCanvas SaveLayerRec through the managed API and adds missing SKColorFilter types. — ❤️ @ahmed605 (#2962, #2882)

Bug Fixes

  • WebAssembly application compatibility — Fixes .NET 9 Blazor behavior and base-path imports, and applies the WASM workaround even when applications do not use Blazor views. (#3064, #3082, #3088, #3092)
  • Legacy project restore and picture images — Restores .NET Framework and Mono projects using packages.config, corrects native package path metadata, and fixes SKImage.FromPicture. — ❤️ @sungaila (#3112, #3100, #3231)

Security

  • Native dependency updates — Refreshes libpng to 1.6.44, libexpat to 2.6.4, FreeType to a 2.13.3-based revision, and VulkanMemoryAllocator to 3.2.1, alongside the libjpeg-turbo dependency refresh. — ❤️ @kasperk81 (#3059, #3056, #3061, #3196, #3060)

HarfBuzzSharp 8.3.1.1

HarfBuzzSharp native assets gain RISC-V and LoongArch64 support and Android 16 KB alignment. Package-path and WASM integration fixes are included; the 8.3.1.1 package revision does not imply a new HarfBuzz engine.
