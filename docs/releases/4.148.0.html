Version 4.148.0

First stable v4 release · Released June 22, 2026 · NuGet · GitHub Release

Supersedes 4.147.0 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.148.0 delivers the first stable v4 release on Skia m148. Variable fonts, color palettes, animated WebP, and explicit sampling join the stable API. Singleton initialization, native-call lifetimes, and pixel spans are hardened. Upgrading from v3 requires attention to text APIs, font defaults, Vulkan configuration, and platform requirements.

Breaking Changes

  • Move text and sampling state out of legacy paint APIs — SKPaint text/font members deprecated in v3 and other legacy overloads are now error-obsolete and absent from the reference surface. Use SKFont for font state and glyph queries, SKSamplingOptions instead of SKFilterQuality, and SKFontHinting instead of SKPaintHinting. Pass sampling and text alignment explicitly. The two SKCanvas.DrawText overloads taking SKFont and SKPaint without SKTextAlign remain warning-only, not errors. (#4068, #4114, #4205)
  • Replace old render-target and text-run helpers — Remaining pre-v4 deprecated APIs become errors. Use the GRBackendRenderTarget constructors without sampleCount for Vulkan and Metal, and replace text-run GetGlyphSpan/GetPositionSpan/GetRotationScaleSpan and SetRotationScale calls with the Glyphs and Positions properties. These changes remove legacy reference-assembly APIs while retaining implementation members for binary compatibility. (#4205)
  • Use SKPathBuilder for geometry construction — Upstream paths are immutable. SKPath mutators remain obsolete compatibility shims; migrate construction to SKPathBuilder and materialize paths with Detach or Snapshot. Prefer the SKPathBuilder destination overloads of GetFillPath and GetSegment. These new v4 deprecations are warnings rather than the pre-v4 errors described above. (#3702)
  • Set fonts explicitly and revise fallback checks — new SKFont() or a null Typeface uses SKTypeface.Empty, producing zero measurements and no glyphs. Pass SKTypeface.Default or an explicit face and detect an empty face with IsEmpty. Legacy paint defaults/reset now seed Default instead of null. FromFamilyName returns Default for an unknown Android family; use SKFontManager.Default.MatchFamily when you need null to distinguish a missing family. (#3730)
  • Validate 32-bit stream move offsets — SKStream.Move(long) is obsolete and uses a checked conversion, throwing OverflowException outside the int range instead of truncating. Validate offsets and use Move(int). The native offset ABI also fixes negative moves on LP64 systems. (#3714)
  • Configure Vulkan 1.1 before creating a context — Ganesh Vulkan requires Vulkan 1.1; a Vulkan 1.0 context can terminate the process rather than returning null. Create the instance with VkApplicationInfo.apiVersion at least 1.1 and explicitly set GRVkBackendContext.MaxAPIVersion to the matching supported version. Do not leave either at zero. Select raster or another backend up front on Vulkan 1.0-only devices. (#3702)
  • Update custom Vulkan interop and conversion types — Use GRVkYcbcrConversionInfo for GRVkImageInfo.YcbcrConversionInfo; review the new Components layout and removed equality operators on the Gr-prefixed shim. GRVkBackendContextNative drops fMinAPIVersion, fInstanceVersion, fExtensions, fFeatures, and fOwnsInstanceAndDevice. Use fVkExtensions and fDeviceFeatures/fDeviceFeatures2; remove old assignments and manage instance/device ownership yourself. (#3560, #3702, #4001)
  • Review derived native-wrapper disposal code — SKNativeObject.IgnorePublicDispose no longer exposes a setter. Subclasses assigning it must remove those assignments and review their disposal and native-handle ownership code against the updated API surface.
  • Check Linux runtime dependencies by architecture — Updated glibc native assets target 2.27 for x86/x64/arm64, 2.35 for arm, 2.39 for riscv64, and 2.42 for loongarch64. Ensure deployments meet the applicable baseline. glibc and musl assets now depend on libstdc++.so.6, already required by the .NET runtime; minimal or custom hosts must supply it. Bionic keeps its static C++ runtime. (#4062)
  • Use supported Tizen and WebAssembly targets — Tizen native assets are now 64-bit only: use tizen-x64 or tizen-arm64 instead of arm/x86. Native WASM linking requires .NET 8 or later for SkiaSharp and HarfBuzzSharp. Blazor managed assemblies still include net6.0, but that does not make .NET 6/7 WASM native linking supported. (#3702, #4022)
  • Update early-preview palette and XPS callers — If migrating from early v4 previews, palette queries now return HBColor instead of raw uint values; use its channel properties or SkiaSharp.HarfBuzz conversion helpers instead of casting to SKColor. SKDocumentXpsOptions.DPI is renamed Dpi. These APIs were introduced during the previews, not in stable v3. (#4000, #4001)

Engine

  • Skia m148 and new color formats — Rolls the v4 previews into Skia m148, including HDR formats, R16Unorm, CICP color spaces, and the new single-channel half-float SKColorType.RF16. Existing public color-type numeric values are preserved. — ❤️ @ramezgerges (#3560, #3660, #3702, #4125)
  • HarfBuzz 14.2.0 engine — Updates bundled HarfBuzz from 8.3.1 to 14.2.0 for improved OpenType shaping, CFF2 subsetting, and font-table handling. Consumed native functions remain compatible; experimental upstream APIs are not newly bound. (#4035)

API Surface

  • Variable fonts and configurable color palettes — Query variation axes and current design positions, clone typefaces at chosen coordinates, and select or override color-font palettes. Span overloads provide buffer-based access, including partial results for undersized variation buffers. — ❤️ @ramezgerges (#3703, #3742)
  • Animated WebP and stream-backed data — Encodes animated WebP from pixmaps and frame durations. SKStream.GetData exposes ref-counted data without copying when cheaply available, returning null otherwise; the data remains valid after stream disposal. (#3771, #3772)
  • Explicit drawing and resource control — Adds surface and bitmap drawing overloads with SKSamplingOptions, XPS document options, resource-specific GPU flush, and shader-backed mask filters. (#3491, #4114, #4001)

Lifecycle & Internals

  • Safe singleton initialization and native-call lifetimes — Lazy per-type singleton initialization breaks startup cycles; protected wrappers no longer free shared native singletons. Native calls keep wrappers alive during interop, and SKPath disposal avoids finalizer-order crashes. — ❤️ @ramezgerges (#4080, #3796)
  • Configure native loading before first use — Native version compatibility is checked on the first SkiaApi call rather than at assembly load, allowing applications to register a resolver or configure native search paths first. (#4133)

Bug Fixes

  • Stride-aware pixel spans — SKPixmap and SKBitmap pixel spans honor RowBytes and row coordinates for non-square images and subsets, ending at the last valid pixel. Nonempty, known-format buffers validate coordinates; multi-row typed spans require element-aligned strides. Empty and Unknown-format buffers still return empty spans. (#4128, #4148)
  • Platform startup and view recovery — Fixes WinUI projection resolution for .NET 9, Android default-font startup and GL view reattachment, and Nano Server font-manager initialization. Apple library TFMs accept base 26.0 workloads, and ContainsGlyphs no longer recurses indefinitely. — ❤️ @ramezgerges, @SimonvBez (#4084, #3730, #3076, #3835, #3798, #3742)
  • Upstream raster and region correctness — Includes m147 fixes for raster-pipeline optimizer accounting, runtime-effect thread safety, and malformed region-data rejection. (#4044)

Platform

  • Linux Bionic assets — Adds linux-bionic x64 and arm64 native assets for SkiaSharp and HarfBuzzSharp without an external fontconfig dependency. — ❤️ @4Darmygeometry (#3217)

Security

  • Native dependency refresh — Updates libexpat to 2.8.1, libpng to 1.6.58, FreeType to 2.14.3, zlib to 1.3.2.1, and libjpeg-turbo to 3.1.4.1. (#4079, #3718, #3726, #3720, #4012)

HarfBuzzSharp 14.2.0

Adds variable-font and named-instance control, color-palette queries, and HBColor conversion helpers. Native-call lifetime protection is strengthened; Linux Bionic assets are available, Tizen is 64-bit only, and native WASM linking requires .NET 8 or later.
