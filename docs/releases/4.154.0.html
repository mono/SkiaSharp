Version 4.154.0

M154 and documentation refresh · NuGet (prerelease)

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.154.0 previews the Skia M154 renderer and ships compiler XML documentation with the packages. The release also updates HarfBuzzSharp generation and disables RAW and DNG image decoding. Review the HarfBuzz compatibility changes before upgrading.

Breaking Changes

  • HarfBuzz combining-class enum name corrected — UnicodeCombiningClass.CCC133 was renamed to CCC132 to match upstream HarfBuzz; update source code that referenced the misspelled member. (#5057)
  • GlyphFlags.Defined is no longer available — The aggregate Defined mask is no longer exposed. Combine the concrete glyph flags required by your application instead. (#5057)

Engine

  • Skia updated to milestone M154 — Updates the bundled renderer with the M154 engine and its subsequent upstream fixes, including GPU buffer-upload and failed-flush cache corrections. (#4945, #5054, #5114, #5253)

API Surface

  • Package XML documentation added — Managed packages now carry compiler-generated XML documentation sidecars, improving API documentation in IDEs and package consumers. (#5053, #5064, #5066, #5078, #5091)

Bug Fixes

  • RAW and DNG decoding disabled — Prevents the bundled decoder from accepting RAW and DNG images in this release line. (#5190)

HarfBuzzSharp 14.2.1.400

HarfBuzzSharp now generates bindings from the HarfBuzz source pinned by Skia and updates the bundled library to 14.2.1. The corrected combining-class enum name and removed aggregate glyph-flag mask require the source changes described above.
