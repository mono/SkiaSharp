Version 4.154.0

Skia m154 release candidate · NuGet (prerelease)

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.154.0 previews Skia m154 and moves API documentation into compiler XML. HarfBuzzSharp bindings now follow the bundled native source; review the renamed combining-class member and removed aggregate glyph flag before upgrading.

Breaking Changes

  • UnicodeCombiningClass.CCC133 renamed to CCC132 — The HarfBuzz upstream spelling correction retains numeric value 132 but removes the compatibility alias. Replace references to CCC133 with CCC132. (#5057)
  • GlyphFlags.Defined removed — The aggregate Defined mask is no longer exposed because it is not an independent option. Combine the concrete glyph flags required by your application instead. (#5057)
  • RAW and DNG decoding disabled — The bundled codec no longer decodes RAW or DNG images. Decode these formats with a dedicated library and provide a supported raster image to SkiaSharp instead. (#5190)

Engine

  • Skia updated to milestone m154 — The bundled renderer moves to Chrome milestone 154 and incorporates current buffer-upload and upstream bug-fix syncs. (#4945, #5054, #5114)

API Surface

  • Compiler XML API documentation — Package consumers receive compiler-generated XML documentation sidecars, with public API documentation authored alongside the C# declarations. (#5053, #5064, #5066, #5078, #5080)

Lifecycle & Internals

  • Bindings generated from bundled HarfBuzz — HarfBuzzSharp generation now uses the HarfBuzz revision pinned by Skia, keeping supported managed declarations synchronized with the bundled native library. (#5056, #5057)
  • View documentation supports Markdown remarks — API documentation remarks can now retain Markdown formatting in generated consumer documentation. (#5091)

HarfBuzzSharp 14.2.1.400

HarfBuzzSharp bindings now generate from the DEPS-pinned native source. The update corrects the CCC132 member name and removes the aggregate GlyphFlags.Defined mask.
