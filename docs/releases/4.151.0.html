Version 4.151.0

Skia m151 performance release · Released July 30, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.151.0 delivers the Skia m151 engine update with faster managed color, shaping, and pixel operations. It also improves WebAssembly support, fixes native resource lifetime issues, and adds zero-copy shaping results for text-heavy applications.

Breaking Changes

None in this release.

Engine

  • Skia updated to milestone m151 — The bundled renderer advances to Chrome milestone 151 with subsequent upstream correction merges. (#4294, #4304)

API Surface

  • SKShaper exposes zero-copy glyph results — Text shaping can read glyph results through spans, avoiding unnecessary managed copies. (#4408)

Bug Fixes

  • Encoded-data subset resources are released — SKImage creation from encoded data with a subset no longer leaks its native resource. (#4389)

Lifecycle & Internals

  • Common color operations run in managed code — Color conversion, premultiplication, tag parsing, and hex parsing avoid recurring interop and allocation overhead. — ❤️ @ramezgerges (#4340, #4376, #4459)

Platform

  • WebAssembly exception handling updated — WASM native libraries and validation are updated for current .NET preview exception-handling support. (#4411, #4415)

HarfBuzzSharp 14.2.1

HarfBuzzSharp improves UTF-8 input handling, tag parsing, and zero-copy shaped-glyph access.
