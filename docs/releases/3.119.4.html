Version 3.119.4

Broader platforms and safer streams · Released May 22, 2026 · NuGet · GitHub Release

Supersedes 3.119.3 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.119.4 adds GTK 4 views and expands native platform coverage while improving stream and loading reliability. Linux Bionic and 64-bit Tizen assets join the package set. Android view reattachment, tvOS simulator linking, reflection-disabled AOT, and Windows CPU-only startup receive fixes, alongside refreshed native dependencies.

Breaking Changes

  • Update platform-specific .NET targets — Platform libraries move to .NET 9 and .NET 10 target sets. Update platform-specific consumers to a compatible target and workload; this does not remove the existing net462 and .NET Standard compatibility targets for core libraries. .NET Framework 4.8 is added and recommended for desktop applications. (#3514, #3631)
  • Do not use the generated Blazor _Imports type as a component — The generated SkiaSharp.Views.Blazor._Imports type no longer derives from ComponentBase or implements its component interfaces. Remove code that instantiates or treats that generated imports type as a Blazor component.

Platform

  • GTK 4 drawing views — Adds SkiaSharp.Views.Gtk4 with SKDrawingArea and GTK/Skia geometry and color conversions using GirCore bindings. A follow-up fix prevents Cairo snapshot assertions during repeated redraws. (#3527, #3562)
  • Bionic and 64-bit Tizen native assets — Adds linux-bionic x64 and arm64 assets for SkiaSharp and HarfBuzzSharp without fontconfig dependencies. Tizen gains x64 and arm64 assets alongside its existing 32-bit targets. — ❤️ @4Darmygeometry (#3217, #3620)

Lifecycle & Internals

  • Independent managed-stream duplicates — SKManagedStream duplicates and forks use a cached, ref-counted SKData snapshot. The original remains readable, multiple duplicates are allowed, and disposing the parent can close the .NET stream without invalidating the duplicates. Non-seekable streams return null for duplicate and fork requests. (#3589)

Bug Fixes

  • Native loading on Linux and Windows — Fixes Linux ARM64 fontconfig loading and LoongArch native linkage. Windows CPU-only rendering can load without Direct3D 12 components, and ANGLE statically links its C runtime to avoid requiring the VC++ Redistributable. (#3494, #3629, #3648, #3633, #3510)
  • Android reattachment and tvOS simulator linking — MAUI Android SKGLView redraws after returning to a tab or page at the same size. tvOS packages and native references distinguish simulator frameworks from device frameworks, preventing simulator link failures. — ❤️ @SimonvBez (#3076, #3561, #3563)
  • Reflection-disabled AOT initialization — SKBlender initializes blend modes without reflection, avoiding TypeInitializationException when IlcDisableReflection=true. (#3485)

Security

  • Native dependency refresh and hardening — Updates libpng to 1.6.58, libwebp to 1.6.0, Brotli to 1.2.0, and libexpat to 2.7.3. Native SkiaSharp builds also enable Spectre mitigation flags on Windows and Linux. — ❤️ @sshumakov (#3723, #3478, #3469, #3458, #3496, #3502)

HarfBuzzSharp 8.3.1.5

HarfBuzzSharp adds Linux Bionic and 64-bit Tizen assets and separates tvOS simulator assets from device frameworks. Its platform target sets move with the .NET 9/10 update; the 8.3.1.5 package revision is not a native engine upgrade.
