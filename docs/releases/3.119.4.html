Version 3.119.4

Cross-platform servicing release · Released May 22, 2026 · NuGet · GitHub Release

Supersedes 3.119.3 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.119.4 improves platform reliability, native hardening, and supported view integrations. It rolls up the 3.119.3 preview work with Linux, Android, Tizen, and desktop fixes.

Breaking Changes

  • Blazor view surface changed — Review the API-diff report and update Blazor view code to use the current supported members before upgrading.

Bug Fixes

  • Android GL views recover after tab switches — MAUI applications no longer leave SKGLView blank after switching TabBar tabs. — ❤️ @SimonvBez (#3076)
  • Linux ARM64 runtime stability improved — Native packaging and runtime dependencies are corrected for Linux ARM64 applications. (#3494)

Platform

  • Tizen and Linux support broadened — The release adds 64-bit Tizen native support and Linux Bionic native assets. — ❤️ @4Darmygeometry (#3620, #3217)
