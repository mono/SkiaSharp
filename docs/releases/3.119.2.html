Version 3.119.2

Native hardening and diagnostic assets · Released February 6, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 3.119.2 strengthens native binaries and makes Android native crashes easier to diagnose. The release also fills gaps in tvOS surface creation APIs without changing the engine milestone.

Breaking Changes

None in this release.

Security

  • Native binary hardening — Enables Control Flow Guard across Windows native DLLs and buffer security checks for HarfBuzz and ANGLE. Adds Spectre mitigation compiler flags for SkiaSharp native libraries on Windows and Linux. — ❤️ @Aguilex (#3397, #3404, #3497, #3503)

API Surface

  • tvOS surface creation parity — Adds the missing SKSurface.Create overloads for tvOS. — ❤️ @MartinZikmund (#3342)

Platform

  • Android native symbols — Preserves and packages Android native symbols to support crash investigation. (#3374)

HarfBuzzSharp 8.3.1.3

HarfBuzzSharp Windows binaries gain Control Flow Guard and buffer security checks, and Android native symbols are preserved for diagnostics. These are package and native-build changes, not a HarfBuzz engine upgrade.
