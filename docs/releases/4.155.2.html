Version 4.155.2

Highlights

SkiaSharp 4.155.2 backports six upstream Skia security fixes and restores WebAssembly builds that link C sources. Managed APIs, the C API and the native ABI are unchanged.

Breaking Changes

None in this release.

Security

  • GPU clip and rounded-rectangle fixes — Backports fixes for a Graphite clip render-step overflow (CVE-2026-126871) and skewed elliptical rounded-rectangle geometry in Ganesh, whose radii are now clamped (CVE-2026-126882). — ❤️ @ramezgerges (#5793)
  • High-severity Skia fixes — Backports fixes for 64-bit image-filter unique IDs (CVE-2026-118340), SkSL invalid-type rejection (CVE-2026-119261), a region-builder out-of-bounds write (CVE-2026-121086) and an analytic antialiasing blitter heap overflow (CVE-2026-126912). — ❤️ @ramezgerges (#5797)

Platform

  • WebAssembly apps linking C sources build again — The WebGPU C++ bindings are now compiled into libSkiaSharp.a, so WebAssembly apps that add their own native C sources, such as Uno Platform 7, link successfully. — ❤️ @ramezgerges (#5797)

HarfBuzzSharp 14.4.0.2

No HarfBuzzSharp binding changes shipped in this release — it rebuilds the same HarfBuzz as the previous line.
