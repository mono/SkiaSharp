Version 4.153.0

Font selection and GPU reliability · Released September 21, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.153.0 updates to Skia m153 with font-fallback and GPU reliability corrections. Linux fallback selection can choose a different face. This release also corrects cached-data destruction, glyph-atlas tracking and GPU-buffer failure handling.

Breaking Changes

  • Pin fonts when fallback selection must be deterministic — Linux fontconfig now tries FcFontMatch before the previous FcFontSort fallback. Applications relying on the exact fallback face may see different glyphs or text metrics; select an explicit family/style or bundle a typeface when deterministic selection matters. (#4826)

Engine

  • Skia m153 — Updates the bundled renderer to milestone 153 without managed API or C ABI changes. HarfBuzzSharp moves to package revision 14.2.1.300 while the native HarfBuzz engine remains 14.2.1. (#4826)

Bug Fixes

  • More reliable GPU text and failure handling — Prevents partial glyph-atlas updates from enabling stale location reuse and propagates render-task and submission failures. Checked buffer-upload failures reject affected draws instead of using stale contents, while triangulated paths retain CPU vertices for retry. (#5062, #5116)
  • Windows HarfBuzz BinSkim compatibility — Corrects the BA2007 disabled-compiler-warnings error in libHarfBuzzSharp.dll on x86, x64 and ARM64, avoiding that transitive-package gate failure without changing the native exports. (#5120)

Lifecycle & Internals

  • Cached-data destruction ordering — Releases the native cached-data mutex guard before deleting its owner, avoiding an unlock through freed memory. (#4927)

HarfBuzzSharp 14.2.1.300

Corrects the Windows libHarfBuzzSharp BinSkim BA2007 disabled-warnings error without changing its exported ABI. Package revision 14.2.1.300 still bundles native HarfBuzz 14.2.1.

Prepared the m153 line for stable release without additional collected product changes.
