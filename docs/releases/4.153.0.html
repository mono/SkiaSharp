Version 4.153.0

Skia m153 stable release · Released September 21, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.153.0 delivers Skia m153 with current upstream rendering correctness fixes. Linux font fallback may select a different face after this engine update; use an explicit or bundled typeface where selection must be deterministic.

Breaking Changes

  • Linux font fallback may select a different face — Skia now tries FcFontMatch before the previous FcFontSort fallback path, which can change selected glyphs or text metrics. Specify a family and style, or bundle the typeface, when deterministic fallback selection matters. (#4826, #4927)

Engine

  • Skia updated to milestone m153 — The bundled renderer moves to Chrome milestone 153 and includes the current upstream correctness, buffer-upload, and bug-fix syncs. (#4826, #4927, #5062, #5116)

HarfBuzzSharp 14.2.1.300

Hardens the bundled HarfBuzzSharp native build configuration without changing its managed API.
