Version 4.152.0

Skia m152 stable release · Released September 5, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.152.0 adds Graphite GPU bindings, asynchronous pixel reads, and the Skia m152 engine. It expands Vulkan support, improves Windows and Nano Server packaging, fixes native lifetime hazards, and streamlines HarfBuzzSharp shaping.

Breaking Changes

None in this release.

Engine

  • Skia updated to milestone m152 — The bundled renderer moves to Chrome milestone 152 and includes upstream servicing, stability, and use-after-free fixes. (#4537, #4538, #4568, #4651, #4808, #4925)

API Surface

  • Graphite GPU backend bindings — Adds managed Graphite bindings for Vulkan, Metal, and Dawn so applications can use Skia's next-generation GPU backend. — ❤️ @ramezgerges (#3968)
  • Asynchronous pixel readback — SKImage and SKSurface gain backend-neutral asynchronous RequestReadPixels support. (#4545)
  • Vulkan Silk.NET integration package — Adds the SkiaSharp.Vulkan.Silk.NET package and restores its production packaging. (#4527, #4841)

Bug Fixes

  • Native pixel-source lifetimes protected — SKPixmap subset and With operations retain their pixel source, avoiding native use-after-free failures. (#4558)
  • SKRegion iterator lifetime fixed — SKRegion.SpanIterator keeps its source region alive while native iteration is in progress. (#4355)
  • Raster-image allocation cleanup — SKImage.Create releases CoTaskMem pixel buffers when raster-image creation fails. (#4455)
  • Runtime-effect uniform buffers released — Resetting SKRuntimeEffectUniforms now disposes the previous native uniform buffer. (#4783)

Platform

  • Nano Server font support — Nano Server uses FreeType for system-font support. — ❤️ @jeffska (#4280)
  • Native symbol packages — Packaging now produces Apple native symbol packages and ensures Android symbols have deterministic identities. (#4843, #4846)

Lifecycle & Internals

  • Less allocation in common operations — SKData.SaveTo, tag formatting, encoded-text access, runtime-effect uniform lookup, and handle registration avoid unnecessary allocations or repeated work. (#4512, #4550, #4630, #4752)
  • HarfBuzz shaping avoids feature-array copies — HarfBuzzSharp Font.Shape no longer defensively copies its Feature array. (#4690)

HarfBuzzSharp 14.2.1.200

HarfBuzzSharp shaping avoids copying Feature arrays, while conversion and packaging work keep the bundled bindings aligned with the release.
