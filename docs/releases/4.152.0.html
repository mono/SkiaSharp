Version 4.152.0

Graphite and m152 · Released September 5, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.152.0 adds Graphite GPU bindings and asynchronous pixel readback on the Skia m152 engine. It also restores Vulkan Silk.NET packages, strengthens object lifetime safety, and improves allocation behavior in frequently used APIs.

Breaking Changes

None in this release.

Engine

  • Skia updated through m152 servicing — Updates the bundled renderer to Chrome milestone m152 and incorporates its subsequent upstream stability and servicing changes. (#4651, #4568, #4538, #4808, #4925)

API Surface

  • Graphite GPU backends are available — Adds Graphite bindings for Vulkan, Metal, and Dawn so applications can target Skia's newer GPU architecture. — ❤️ @ramezgerges (#3968)
  • Asynchronous pixel readback added — SKImage and SKSurface can request pixels asynchronously through a backend-neutral API. (#4545)
  • NuGet package guidance improved — Package READMEs now provide clearer usage information directly where consumers install SkiaSharp packages. (#4714)

Bug Fixes

  • Pixel and region views retain their sources — SKPixmap-derived views and SKRegion span iteration now keep their backing objects alive while native code uses them. (#4355, #4558)
  • Failed raster image creation releases pixel memory — The raster-image failure path no longer leaves its CoTaskMem pixel buffer allocated. (#4455)
  • Runtime-effect reset releases replaced buffers — Resetting SKRuntimeEffectUniforms disposes the previous uniform buffer before replacing it. (#4783)
  • HarfBuzz blob conversion releases stream assets — Converting non-memory-backed streams to HarfBuzz blobs no longer retains the temporary SKStreamAsset. (#4710)

Lifecycle & Internals

  • Common conversion paths allocate less — SKData.SaveTo, encoded-text handling, tag formatting, and runtime-effect uniform lookup avoid unnecessary copies, boxing, strings, and collection growth. (#4550, #4498, #4752, #4512)
  • Handle lookup startup work is reduced — HandleDictionary caches its reflection-based skip-registration check instead of repeating it during initialization. (#4630)

Platform

  • Vulkan Silk.NET package support restored — SkiaSharp.Vulkan.Silk.NET is again produced and its Vulkan coverage extends to Android and Linux. (#4527, #4841)
  • Nano Server includes FreeType fonts — Native Nano Server assets now use FreeType to provide font support. — ❤️ @jeffska (#4280)
  • Apple symbol packages are generated — Pack output now includes native symbols for Apple platforms to improve post-deployment diagnostics. (#4846)

HarfBuzzSharp 14.2.1.200

HarfBuzz shaping avoids an unnecessary feature-array copy, and converting non-memory-backed streams to blobs now releases temporary stream assets.
