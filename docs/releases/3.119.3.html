Highlights

SkiaSharp 3.119.3 previews Linux ARM64 reliability fixes and refreshed bundled native dependencies. It also fixes an ahead-of-time compilation crash in applications that disable reflection.

Breaking Changes

None in this preview line.

Bug Fixes

  • Linux ARM64 startup fixed — The cross-compile sysroot now includes the required fontconfig runtime library, preventing a native crash on Linux ARM64. (#3494)
  • AOT applications no longer crash without reflection — Applications compiled with IlcDisableReflection enabled can load SkiaSharp safely. (#3485)

Security

  • Bundled native dependencies refreshed — The preview updates libpng, libwebp, brotli, and the Skia submodule. (#3452, #3469, #3478, #3474)

HarfBuzzSharp 8.3.1.4

No HarfBuzzSharp binding changes shipped in this release — it rebuilds the same HarfBuzz as the previous line.
