Version 4.155.0

M155 engine and interoperability · NuGet (prerelease)

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.155.0 advances to Skia m155 with servicing fixes and refreshed HarfBuzzSharp support. It also updates GLES interop for pointer-based platform calls and disables RAW and DNG decoding while retaining source and binary compatibility.

Breaking Changes

None in this preview line.

Engine

  • Skia updated to milestone M155 — Updates the bundled renderer to Chrome milestone M155 and incorporates later upstream fixes, including corrections for failed-flush cache entries and FontConfig family matching. (#5081, #5196, #5286)

API Surface

  • GLES platform interop uses explicit pointers — GLES and WinUI EGL interop now use blittable pointer-based calls, with existing platform callers pinned explicitly instead of relying on managed array and string marshalling. (#5155)
  • HarfBuzzSharp 14.4 OpenType tags exposed — The HarfBuzzSharp update provides documented OpenType bit and number tag enums for usable native tag values without exposing raw native-shaped APIs. (#5135)

Bug Fixes

  • RAW and DNG decoding disabled — The bundled decoder no longer accepts RAW or DNG images. The SKEncodedImageFormat.Dng value remains available for source and binary compatibility, but it does not indicate codec support. (#5162)

HarfBuzzSharp 14.4.0

HarfBuzzSharp now ships with HarfBuzz 14.4.0 and adds documented OpenType bit and number tag enums while keeping raw native fetch helpers internal.
