Version 4.155.0

M155 preview line · NuGet (prerelease)

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.155.0 brings the Skia M155 renderer and current HarfBuzz bindings to preview consumers. It also updates GLES interop and disables RAW and DNG decoding. Test applications that use these image formats or low-level OpenGL interop before adopting the preview.

Breaking Changes

None in this preview line.

Engine

  • Skia updated to milestone M155 — Aligns the bundled renderer with Skia M155 and includes the latest upstream servicing fixes. (#5081, #5196, #5286)

API Surface

  • GLES interop uses pointer-based signatures — Updates the low-level GLES interop surface to pass native pointer values directly. (#5155)

Bug Fixes

  • RAW and DNG decoding disabled — Prevents the bundled decoder from accepting RAW and DNG images in this release line. (#5162)

HarfBuzzSharp 14.4.0

Updates the bundled HarfBuzz library and managed bindings to version 14.4.0.
