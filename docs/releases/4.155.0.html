Version 4.155.0

HarfBuzz refresh and font matching · Released October 29, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.155.0 combines Skia m155 with HarfBuzz 14.4.0 and Linux font-matching corrections. The release improves failed-flush cache cleanup and updates HarfBuzz shaping behavior. Built-in RAW/DNG decoding and embedded RAW-preview extraction are disabled.

Breaking Changes

  • Decode RAW and DNG images outside SkiaSharp — The bundled DNG SDK and PIEX decoding routes are disabled, including extraction of embedded JPEG previews from RAW files. Use an external decoder and pass pixels or an extracted JPEG to SkiaSharp. SKEncodedImageFormat.Dng remains for compatibility, but no replacement RAW backend is included. (#5162)
  • Review cross-direction mark positioning — HarfBuzz 14.4.0 intentionally changes cross-direction mark positioning for DirectWrite and Core Text compatibility. Review text layouts and rendering baselines that depend on the previous mark positions when upgrading. (#5135)

Engine

  • Skia m155 — Updates the bundled renderer to milestone 155 while preserving the managed API and the explicit bounds behavior of rotation-scale text runs. (#5081)
  • HarfBuzz 14.4.0 — Updates the shaping engine with intentional cross-direction mark-positioning changes, glyph-position saturation, malformed-font crash and hang fixes, and shaping and subsetting performance work. HarfBuzzSharp packages start a new 14.4.0 revision line. (#5135)

API Surface

  • OpenType tag enums — Adds OpenTypeBitsTag and OpenTypeNumberTag enum values for the updated native source. The raw fetch functions remain internal; no Face wrappers are introduced. (#5135)

Bug Fixes

  • Linux font-family candidate matching — Checks family acceptability only on the first valid sorted fontconfig candidate, rather than accepting a lower-ranked metric-compatible substitute and preventing the caller from trying its next requested family. (#5286)
  • Failed-flush cache cleanup — Drops uniquely held Ganesh thread-safe-cache entries after a failed flush so later draws cannot reuse those entries' uninitialized textures. (#5286)
