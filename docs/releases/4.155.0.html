Version 4.155.0

Skia m155 preview · NuGet (prerelease)

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.155.0 previews Skia m155 with updated HarfBuzz and GLES interop. It disables RAW and DNG decoding, updates HarfBuzz to 14.4.0, and incorporates current m155 renderer fixes.

Breaking Changes

  • RAW and DNG decoding disabled — The bundled codec no longer decodes RAW or DNG images. Decode these formats with a dedicated library and provide a supported raster image to SkiaSharp instead. (#5162)

Engine

  • Skia updated to milestone m155 — The bundled renderer moves to Chrome milestone 155 and includes the latest upstream bug-fix sync. (#5081, #5196)

API Surface

  • Pointer-based GLES interop — GLES interop signatures use pointer-based forms for direct native interoperation. (#5155)

Lifecycle & Internals

  • HarfBuzz updated to 14.4.0 — Updates the bundled HarfBuzz engine and its corresponding HarfBuzzSharp release. (#5135)
