Version 4.159.0 (Unreleased)

Modern UWP drawing controls

Highlights

Modern .NET UWP apps gain CPU and ANGLE-backed GPU drawing controls for the in-box Windows XAML stack. The new UWP integration targets .NET 10 and remains separate from WinUI. It does not restore legacy uap10.0 support.

Breaking Changes

None in this preview line.

Platform

  • Modern .NET UWP support — SkiaSharp.Views.UWP targets net10.0-windows10.0.26100.0 with a declared Windows minimum of 10.0.17763.0. SkiaSharp.NativeAssets.UWP supplies ANGLE and native integration for win-x86, win-x64 and win-arm64, reusing the core Win32 Skia and HarfBuzz binaries. This is not legacy uap10.0 support or a Store-certification claim. — ❤️ @FoggyFinder (#4540)

API Surface

  • CPU and GPU XAML controls — Use SKXamlCanvas for CPU drawing and SKSwapChainPanel for ANGLE-backed GPU drawing in SkiaSharp.Views.UWP. PaintSurface callbacks receive control-managed surfaces: CPU surfaces are disposed after the callback, while GPU resources are released when the context is destroyed. The documented sample workflow requires Visual Studio 2026 MSBuild and deployment. — ❤️ @FoggyFinder (#4540)
