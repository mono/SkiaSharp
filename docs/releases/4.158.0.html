Version 4.158.0

Skia m158 rendering corrections · Released November 26, 2026 · NuGet · GitHub Release

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.158.0 brings Skia m158 with corrections to filtered images, glyph rendering and GPU failure handling. The SkiaSharp managed API remains unchanged. Co-shipping HarfBuzzSharp upgrades to HarfBuzz 15.0.0 and adds named script constants while preserving its existing Script programming model.

Breaking Changes

None in this release.

Engine

  • Skia m158 — Updates the bundled renderer to milestone 158 and incorporates subsequent m158 fixes without changing the SkiaSharp managed binding surface. (#5634, #5702, #5839)

Bug Fixes

  • Filtered images stay within their intended pixels — Antialiased, minified and skewed draws retain texture-subset clamping where needed, and filtered scratch images avoid sampling unwritten mipmap texels. Displacement offsets now use the same precision as filter bounds, and image-filter cache equality agrees with hashing. (#5712, #5768, #5839)
  • Glyph formats and LCD cropping respected — Mask-filtered glyphs use regenerated outlines and compatible mask formats, clear clipped output and preserve full 3D plane strides. FreeType LCD16 glyph bounds are converted to pixel coordinates before consistent cropping, with checks on bitmap dimensions and buffer bounds. (#5739, #5839)
  • Hairline caps and text-atlas selection corrected — Reflected transforms no longer incorrectly enlarge zero-length square-capped hairlines. Text-atlas sampler selection tolerates interpolation imprecision for ordinary and LCD glyph lookups. (#5669)
  • GPU failures and oversized allocations handled safely — Ganesh propagates native flush and synchronous Vulkan wait failures; GRContext.Submit remains void. Invalid buffer sizes and oversized Imagination MSAA attachments are rejected. Affected ARM Vulkan device-loss paths delay teardown, and Imagination out-of-memory paths avoid unsafe descriptor-pool destruction. (#5669, #5712, #5839)
  • GPU draw bounds and ordering preserved — Destination reads are constrained to their intended bounds. Graphite rejects draws whose clips cannot fit a fresh render pass and resets depth after full-overwrite draws to preserve painter order. (#5669, #5839)

Lifecycle & Internals

  • Hash-code seed uses OS randomness — The shared HashCode polyfill in SkiaSharp and HarfBuzzSharp now uses cryptographic randomness for its seed. Hash codes remain randomized between processes and stable within a process; first use now initializes the cryptography library. — ❤️ @rolfbjarne (#5408)

HarfBuzzSharp 15.0.0

Upgrades bundled HarfBuzz to 15.0.0 and adds 30 named Script constants, including Jurchen, ProtoCuneiform and Seal. Existing constants, parsing, numeric conversions and horizontal-direction lookup are preserved; Font(Face) continues to construct fonts through hb_font_create.
