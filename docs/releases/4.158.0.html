Highlights

SkiaSharp 4.158.0 previews Skia m158 and HarfBuzz 15.0.0, with new script constants and GPU rendering fixes. Release Candidate 1 corrects filtered image subsets, image-filter cache keys and mask-filtered glyph rendering. Earlier previews improved reflected hairlines, clipping and displacement precision. SkiaSharp managed signatures remain unchanged; HarfBuzzSharp adds 30 named Script values.

Breaking Changes

None in this preview line.

Engine

  • Skia milestone 158 — Updates the bundled renderer to m158 without changing SkiaSharp managed bindings. The initial preview used HarfBuzzSharp package revision 14.4.0.300 with native HarfBuzz 14.4.0; Preview 2 separately introduced the HarfBuzz 15.0.0 engine upgrade. (#5634, #5554)

Bug Fixes

  • Filtered images respect texture subset bounds — Retains sampling constraints under minification, strong skew, antialiased clips and MSAA so unrelated backing-texture pixels do not leak into filtered output. Image-filter cache keys now use equality consistent with their bytewise hash. (#5768)
  • Mask-filtered glyphs honor reloaded formats and strides — Uses the regenerated glyph's own outline and mask format. Incompatible masks produce cleared output, and clipped embossed glyphs retain full plane strides, avoiding invalid copies, format assertions and uncleared mask planes. (#5739)
  • GPU clipping, hairlines and displacement corrected — Fixes reflected hairline cap sizes, text-atlas selection and Graphite clip capacity. Displacement offsets use fp32 arithmetic. Native synchronous Vulkan submission accounts for fence-wait failures, but GRContext.Submit remains void; the ARM driver device-loss delay is limited to affected versions 42 through below 56. (#5669, #5712)

Lifecycle & Internals

  • OS-generated hash seeds — The shared hash-code polyfill uses OS-generated randomness for its per-process seed in both SkiaSharp and HarfBuzzSharp. Hash codes remain stable within a process and randomized between processes. — ❤️ @rolfbjarne (#5408)

HarfBuzzSharp 15.0.0

Upgrades the bundled engine to HarfBuzz 15.0.0 and adds 30 named Script constants, including Jurchen, ProtoCuneiform and Seal. Existing Script fields, parsing, numeric conversions and horizontal-direction lookup remain available.
