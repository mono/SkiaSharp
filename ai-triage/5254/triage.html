Summary

The Sync - Skia Upstream workflow failed because its staged create-pull-request output targeted a release branch that was not allowed as a base-branch override.

Analysis

The workflow resolves either a manually supplied base branch or a release branch and passes it to its staged pull-request completion signal. The safe-output declaration has no allowed-base-branches configuration, so the policy rejects that valid resolved target.

Evidence

Workflow run 37048491850 reproduces the rejection: create_pull_request: Base branch override is not allowed. Draft PR #5259 contains the proposed allowlist change and regression coverage.

Investigation

  • .github/workflows/auto-skia-sync.md accepts target_branch and declares staged create-pull-request without an allowlist.
  • .github/scripts/skia-sync-detect.sh resolves and emits base_branch for the later stages.
  • .github/workflows/auto-skia-sync.lock.yml contains no allowed-base-branches safe-output setting.

Recommendation

Merge the safe-output base-branch allowlist from PR #5259, then regenerate and verify the compiled workflow configuration.
