Version 4.148.0

First stable v4 release · Released June 22, 2026 · NuGet · GitHub Release

Supersedes 4.147.0 · Rolls up preview-only work that was never released as stable — those changes are included cumulatively below.

API changes · SkiaSharp API diff · HarfBuzzSharp API diff

Highlights

SkiaSharp 4.148.0 is the first stable v4 release, built on Skia m148. It adds variable and color fonts, animated WebP encoding, and reworks the singleton lifecycle. This is a breaking release with several behavioral changes from the m132/m147/m148 Skia upgrade — check the changes below before upgrading.

Breaking Changes

  • New SKFont() now has an empty typeface instead of a lazy default — new SKFont().Typeface used to resolve to the platform default at draw time; it now stores SKTypeface.Empty, so MeasureText returns 0 and nothing draws. Construct with an explicit typeface (e.g. new SKFont(SKTypeface.Default)) and detect "unset" with Typeface.IsEmpty instead of a null check. (#4125)
  • new SKPaint().Typeface now returns Default instead of null — SkiaSharp still seeds a usable default font, but code that checked paint.Typeface == null to detect "no typeface set" no longer fires. Use Typeface.IsEmpty, or drop the check. (#4125)
  • SKTypeface.FromFamilyName("missing") no longer returns null on Android — All platforms are now consistent and return SKTypeface.Default for an unknown family. For a strict "was it actually found?" check, use SKFontManager.Default.MatchFamily(name, style), which still returns null on no match. (#4125)
  • SKTypeface.Default is now guaranteed non-null — Default resolution moved to the font manager; behavior is unchanged on macOS/Windows/Linux, and Android API 36+ now falls back to SKTypeface.Empty instead of crashing. (#4125)
  • SKStream.Move(long) now throws and is obsolete — The overload used to silently truncate out-of-range offsets to a native 32-bit int. It now throws OverflowException for out-of-range values and is marked [Obsolete] (CS0618). Call Move(int) with an in-range, validated offset instead. (#4125)
  • GRContext.CreateVulkan aborts the process on Vulkan 1.0 instead of returning null — Ganesh now requires Vulkan 1.1 and calls a fatal native abort — not a catchable exception — when the instance/device version is below 1.1. Declare VK_API_VERSION_1_1 on both the VkApplicationInfo used to create the instance and on GRVkBackendContext.MaxAPIVersion (do not leave MaxAPIVersion at its unsafe default of 0). Vulkan-1.0-only hardware can no longer run Ganesh Vulkan and must fall back to another backend. (#3741)
  • GRVkBackendContextNative dropped five interop fields — fMinAPIVersion, fInstanceVersion, fExtensions, fFeatures, and fOwnsInstanceAndDevice were removed. Delete those assignments; use fVkExtensions instead of fExtensions and fDeviceFeatures/fDeviceFeatures2 instead of fFeatures. Skia no longer manages instance/device ownership through the backend context. (#3741)
  • GrVkYcbcrConversionInfo layout and identity changed — The struct gained a new Components field (backed by GRVkYcbcrComponents), and GRVkImageInfo.YcbcrConversionInfo retyped from GrVkYcbcrConversionInfo to GRVkYcbcrConversionInfo, losing value-equality (Equals/== / != are gone). Code that manually builds the struct or compares instances for equality must be updated. (#3741)
  • SKNativeObject.IgnorePublicDispose lost its public setter — The property is now get-only from outside the type. Remove any external assignment to it. (#4205)

Engine

  • Skia bumped through m132, m133, m147, to m148 — Brings the bundled Skia engine up to the m148 upstream release line, the basis for this v4 line, plus the ongoing chrome/m147 upstream bug-fix merges. — ❤️ @ramezgerges (#3560, #3660, #3702, #4125, #4044, #4081)

API Surface

  • Variable and color fonts — Adds variable font support across SkiaSharp and HarfBuzzSharp, plus color font palette selection, with improved variable font robustness. — ❤️ @ramezgerges (#3703, #3742)
  • Animated WebP encoding and zero-copy stream data — SKWebpEncoder can now encode animated WebP images, and SKStream.GetData() converts a stream to SKData without an extra copy. (#3771, #3772)
  • SKSamplingOptions on surface drawing — SKSurface.Draw and SKCanvas.DrawSurface now accept SKSamplingOptions to control filtering when compositing surfaces. (#3491)
  • HarfBuzz HBColor and API cleanup — Adds an HBColor struct for hb_color_t, plus missing API wrappers and naming-convention fixes across the binding. (#4000, #4001)
  • Legacy pre-v4 obsoletes promoted to compile errors — Remaining pre-v4 obsolete APIs (legacy paint text/font state, and other trimmed obsolete enum members) now fail to compile instead of just warning, completing the v3-to-v4 migration path. — ❤️ @ramezgerges (#4068, #4114, #4205)

Bug Fixes

  • Pixel access corrected — SKPixmap/SKBitmap.GetPixelSpan now uses RowBytes for stride and the correct axis (Width, not Height) for the (x, y) overload's offset, fixing incorrect pixel reads. (#4148, #4128)
  • SKPath finalizer crash fixed — Fixes a crash when the SKPathBuilder backing an SKPath is collected before the path itself. — ❤️ @ramezgerges (#3796)
  • Default-typeface resolution moved to managed code — Fixes a null-typeface crash on newer Android by resolving the default typeface in the managed layer instead of relying on the native platform path. — ❤️ @ramezgerges (#3730)
  • Android SKGLView rendering after tab switch — Fixes SKGLView failing to render again after switching tabs in a MAUI TabBar. — ❤️ @SimonvBez (#3076)
  • Apple and WinUI packaging fixes — Corrects Apple platform TFMs (26.0 for libraries, unversioned for apps) and fixes a missing WinUI projection DLL for .NET 9 consumers. (#3798, #4084)

Lifecycle & Internals

  • Singleton lifecycle reworked — Reworks how SkiaSharp's native singleton instances are created and torn down, and moves the native-compatibility gate from a module initializer into the SkiaApi static constructor for more predictable startup. — ❤️ @ramezgerges (#4080, #4133)

Platform

  • New native targets added — Adds Linux Bionic native asset support and Tizen x64/arm64 native builds. — ❤️ @4Darmygeometry (#3217, #3620)
  • WASM Emscripten floor raised — Drops native builds for pre-.NET 8 Emscripten versions. (#4022)

Security

  • Bundled native dependencies refreshed — Updates expat, HarfBuzz, libjpeg-turbo, FreeType, zlib, libpng, and libexpat to their latest versions. (#4079, #4035, #4012, #3726, #3720, #3718, #3717)

HarfBuzzSharp 14.2.0

Adds an HBColor struct for hb_color_t along with variable font shaping support, and bumps the bundled HarfBuzz to 14.2.0.
